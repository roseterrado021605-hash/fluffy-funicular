# Rosmilyn Terrado — Student Portfolio

A responsive portfolio website for a BS Information Technology student. Includes an introduction, skills, academic projects, a resume page, and contact links.

## Files
- `index.html` — main portfolio website
- `resume.html` — printable resume (use **Print / Save as PDF**)
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation menu

## Before publishing
1. Replace `your.email@example.com` with your professional email.
2. Replace `yourusername` with your GitHub username.
3. Update education dates, internship availability, and any missing details.
4. Remove or update any skills and projects that don't reflect your actual experience.
5. Consider leaving your phone number off the public website and adding it only to resumes sent directly to employers.

## Publish with GitHub Pages
1. Create a repository named `yourusername.github.io` (use your own GitHub username).
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. After deployment, your site will be available at `https://yourusername.github.io`.

You can also use a repository with another name and enable Pages in its Settings.

## Preview locally
Open `index.html` in a browser. The resume is available from the **View resume** buttons.
