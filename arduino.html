Arduino RFID Door Lock

A door lock prototype built with an Arduino Uno. Tapping an RFID card on the reader checks the card, and the right card unlocks the door with a servo-driven latch while an LCD screen tells the user what is happening.

How it works

The program running on the Arduino follows these steps:

  1. The LCD greets the userIt shows Welcome! Put your card while it waits for a card.
  2. A card is tapped on the readerThe RC522 module reads the card's ID (UID).
  3. The ID is checkedThe sketch compares the card's UID with the saved ID.
  4. Right card: the door unlocksThe servo moves the latch and the LCD shows Door is unlocked.
  5. Same card again: the door locksThe servo moves the latch back and the LCD shows Door is locked.
  6. Wrong card: access deniedThe door stays as it is and the LCD shows Wrong card!
Parts

What we used

Controller

Arduino Uno

The board that runs the program and controls every part.

Input

RFID-RC522 reader

Reads the card or key fob that is tapped on it.

Display

16x2 LCD

Shows messages like "Put your card" and "Door is unlocked".

Output

Servo motor

Moves the sliding latch to lock and unlock the door.

Lock

Sliding bolt latch

The part that physically keeps the door closed.

Body

Wooden enclosure

A plywood box with a door and a window for the LCD.

Software

Arduino IDE 2.3.3

Used to write the sketch and upload it to the board.

Wiring

Jumper wires & USB

Connect every module and power the Arduino.
